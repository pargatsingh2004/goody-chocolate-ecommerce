                        QUICK START (AFTER DOWNLOAD)
================================================================================

1. Download the ZIP file: goody-chocolate-ecommerce-complete.zip

2. Extract the ZIP:
   - Windows: Right-click → Extract All
   - macOS: Double-click (auto-extracts)
   - Linux: unzip goody-chocolate-ecommerce-complete.zip

3. Open terminal in extracted folder:
   cd goody-chocolate-site-updated/goody-app/goody

4. Create virtual environment:
   python -m venv venv
   source venv/bin/activate    # macOS/Linux
   OR
   venv\Scripts\activate       # Windows

5. Install dependencies:
   pip install -r ../requirements.txt

6. Configure email (.env file):
   cp .env.example .env
   # Edit .env with your Gmail/SendGrid SMTP credentials

7. Setup database:
   python manage.py makemigrations
   python manage.py migrate
   python manage.py createsuperuser

8. Run the server:
   python manage.py runserver

9. Access the application:
   Customer site: http://127.0.0.1:8000/
   Admin panel: http://127.0.0.1:8000/control-panel/
   Django admin: http://127.0.0.1:8000/django-admin/

Done! You're running a complete e-commerce platform! 🎉

================================================================================
                        TROUBLESHOOTING
================================================================================

"No module named 'django'"
→ Virtual environment not activated
→ Run: source venv/bin/activate (or venv\Scripts\activate on Windows)

Emails not sending
→ Check .env file has correct SMTP credentials
→ Try with console backend first (no SMTP needed)
→ For Gmail: Use App Password, not regular password

Port 8000 already in use
→ Run: python manage.py runserver 8001

Admin panel shows 404
→ Run: python manage.py migrate
→ User must be superuser (created with createsuperuser)

Still stuck?
→ See SETUP.md inside the ZIP file (detailed troubleshooting)
